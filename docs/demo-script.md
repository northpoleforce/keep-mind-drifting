# Demo Script (2-3 Minutes)

## Goal

Show that Evermemos persists and reuses thought context while flow graph updates in real time.

## Sequence

1. Start with one user message on topic A.
2. Send message on topic B (clear shift).
3. Send message on topic C (second shift).
4. Return to topic A and highlight reconnection.
5. Show replay/history is reconstructable from memory.

## Presenter Cues

- Call out each new node animation.
- Explain that message and topic node are both persisted in Evermemos.
- Point to context-aware response placeholder and retrieval counts.
